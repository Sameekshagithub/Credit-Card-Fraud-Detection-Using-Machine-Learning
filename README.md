# Credit-Card-Fraud-Detection-Using-Machine-Learning
End-to-end ML pipeline for detecting fraudulent credit card transactions. Compares 7 algorithms (Logistic Regression, KNN, Naive Bayes, Decision Tree, Random Forest, Gradient Boosting, XGBoost) with SMOTE imbalance handling and PR-AUC/F1/ROC-AUC evaluation. Includes dataset, notebook &amp; README
